## 1. 頂点・辺・グラフ

### 意味
- **頂点（ノード）**: 点。人・都市・マスなど
- **辺（エッジ）**: 点と点を結ぶ線。道・友達関係など
- **グラフ**: 頂点と辺の集まり

```python
# 隣接リスト（いちばんよく使う）
N, M = 4, 3
g = [[] for _ in range(N)]
edges = [(0, 1), (1, 2), (0, 3)]
for u, v in edges:
    g[u].append(v)
    g[v].append(u)  # 無向なら両方
```

---

## 2. 有向グラフ／無向グラフ

| 種類 | 意味 | 実装 |
|---|---|---|
| 無向 | 双方向に通れる | `g[u].append(v)` と `g[v].append(u)` |
| 有向 | 矢印の向きにだけ進める | 片方だけ `append` |

問題文の「一方通行」「友達は双方向」で判断します。

---

## 3. 次数

### 意味
その頂点に繋がっている辺の本数（有向なら入次数・出次数）。

```python
deg = [0] * N
for u, v in edges:
    deg[u] += 1
    deg[v] += 1
```

---

## 4. パス・閉路（サイクル）

### 意味
- **パス**: 頂点をたどる道（途中で同じ頂点を繰り返さないことが多い）
- **閉路**: 始点に戻ってこられる道

「閉路がない」→ 木や DAG の話に繋がりやすいです。

---

## 5. 連結・連結成分

### 意味
どの 2 頂点も道で行き来できるなら **連結**。  
バラバラのかたまりが **連結成分**。

| 操作 | 使うもの |
|---|---|
| 辺を追加しながら同じ成分か聞く | [Union-Find](lib/union_find.py) |
| グラフを一度作って探索 | BFS/DFS（[lib/graph.py](lib/graph.py)） |

## 6. 木（tree）

### 意味
次のどれか（全部同じ意味）:
- 連結かつ閉路なし
- 頂点 N・辺 N-1 の連結グラフ
- どの 2 頂点も道がただ 1 本

根を決めて親子関係で扱うことが多いです。

## 9. 二部グラフ

### 意味
頂点を 2 グループに分け、辺は「グループをまたぐ」だけになるグラフ。  
⇔ 奇数長の閉路がない ⇔ 2 色で塗り分け可能。

```python
# BFS で 2 色塗り
def is_bipartite(n, edges):
    g = [[] for _ in range(n)]
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)
    color = [-1] * n
    from collections import deque
    for s in range(n):
        if color[s] != -1:
            continue
        q = deque([s])
        color[s] = 0
        while q:
            v = q.popleft()
            for to in g[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)
                elif color[to] == color[v]:
                    return False
    return True
```

マッチングは → [lib/maxflow.py](lib/maxflow.py) の `bipartite_matching`

## 10. 最短路

| 辺の重み | アルゴリズム | 計算量の目安 |
|---|---|---|
| すべて 1（または同じ） | **BFS** | `O(N+M)` |
| 非負の重み | **Dijkstra** | `O((N+M) log N)` |
| 負の辺あり | Bellman-Ford 等（ABC では少なめ） | `O(NM)` |

迷路・グリッドも「マスが頂点、上下左右が辺」のグラフです。  
→ [lib/graph.py](lib/graph.py)

---

## 11. 最大流・最小カット

### 意味
- **最大流**: 始点から終点へ流せる最大量
- **最小カット**: 始点側と終点側を分断する辺の容量和の最小（＝最大流）

二部マッチングも流れのモデルで解けます。  
→ [lib/maxflow.py](lib/maxflow.py)
