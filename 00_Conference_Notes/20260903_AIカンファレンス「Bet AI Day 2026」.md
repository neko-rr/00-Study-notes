# 12:10-12:50	AIを「使う」から、AIが「働く」へ ― LayerXが進める「組織AI」の社会実装 代表取締役 CTO 松本 勇気
- 体調不良者の代打でそのままCEOが発表
- 1年前：スピード重視
  - まずは、AIを試そう
  - 業務の自動運転
    - 現在：特定条件は、レベル5：完全自動運転
- この1年の4つの環境的変化
  - 自立実行性能の向上
  - Token MaxxingからToken Economicsへ
  - 作る事の価値の低下
- 能力向上
  - ベンチマークの飽和
  - 「人間超え」の性能
  - Loopの設計・自律化
  - 圧倒的な低価格化
- 作る事が希少ではなくなった
  - 何を作るか決める事の重みが大きくなる
- トークン
  - 会社に影響与えるレベルで使うのは、辞めよう
  - 最適化
  - トークン利用料は、むしろ増えているが、アウトカムも最適化も進んでいる
  - これから、色んな会社がこの山を登っていく
    - 試して⇒最適化
- イベント起点のAgent
  - チャットは、必ず指示が必要
  - イベントだと、裁量性が高い
- 個人AIから組織AIへ
  - 個人で慣れる期間は、必ず必要だと考える
    - 企業価値に効いてくるかは、個人でかなり違う
    - しかも、知識が閉じやすい
  - 今年のテーマは、組織AIをどうやって育てていくか
    - 社員をオンボーディングするように扱う⇒進化：事例から学ぶ改善ループ
    - ハーネスを改善する事で、学習機能を付ける
- 具体的にどう取り組んだか
  - 徹底的な利用
    - 昨年12月から急激な利用増加
    - 平均30万円/人・月のLLM内部活用
    - ポイント：エンジニア以外も使用した
  - 開発の加速
    - Commit等ベースに見る開発速度は3倍以上
    - バクラクだけでも毎月以上のペースで新規プロダクト公開
  - プロダクトのAgent　Native化
    - 全てのプロダクトにAgent機能の導入、Agent時代の価値追求
  - R&Dの加速
    - Agent Nativeな世界を実現するための新技術開発
  - 経営のAI　Native化
    - Sales、HRにおけるAgent　Nativeなプロセスへの変化
- 商談動画を3年前から全部録画している
  - お客様の許可ありだけ
  - 商談ロープレやAI、講座が社内にある
    - その人が苦手な事を集中的に練習する
- 半期に1回評価
  - AIを使用して、評価を助ける仕組みもある
  - 全部覚えているのが難しいので、それを助ける
- トークンマネジメントと生産性：Shepherd：シェーパード（羊のロゴ）
  - トークンマネジメントのためのLLM　Gateway等の投入で、コントロールされた活用へ
  - LLM　Gateway
    - 個人レベルで安いモデルの選定やプロンプト改善ができる
- AIによるボトルネックの移動
  - よく言われるのもの
    - 仕様・検証にボトルネックが移動
- デジタル化のボトルネックを解消し続ける
  - 検証（セキュリティ）やAI-BPOによる確実なデジタル化、内側からのデジタル化などのあらゆる手段を取り続ける
    - 社内でもペネトレーションテストを活用しているし、外部にも売っている
- FDE
  - 業務の大半は、業務理解の時間
- Agent　Nativeな組織運営モデル「Agent Nervous System」
  - 神経に例える、感覚神経Agent⇒（意思決定精度向上）運動神経Agent
  - 異常値だけ報告
    - 苦手を洗い出して、その苦手を仕組変更で無くす
  - 行動を変化させられるように、インセンティブを変更する設計ループ
- 業務完了のために今必要なのは、AI Builder
- 業務を終わらせる組織AIを生み出そう
  - AIと共に働く社会を作ろう
