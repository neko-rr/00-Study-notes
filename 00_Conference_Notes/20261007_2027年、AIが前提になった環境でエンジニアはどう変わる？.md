# 2027年、AIが前提になった環境でエンジニアはどう変わる？

# 内容
- 開発業務にAI利用9割超え
  - 半数以上のエンジニアがコードの75%以上をAIで作成している
- 30代エンジニアが「キャリアの不安」を感じている
- これまでもあった「プレイヤーorマネジメント」というキャリア選択の悩みが、AIの普及によってより一層複雑化
  - マネジメント層がビジネススキルを向上させたがっている
- 採用、シニア重視に転換している
  - ジュニアが厳しい
  - スタートアップや内製化が進んでいる所は、ジュニアを見送る
  - 受託は、育成枠でジュニアを取ったり
- 育成の仕方を模索中
  - 会社によっては、AI使用しない時間を設けて、育成したりしている
- この1年で明確にAIへの投資を強めた企業は増えたが、”実感”ではなく”実態”として、AIによる生産性向上を実現できた企業は実は多くない
- ベンチャー企業では、徐々にPR数の総量が増えつつあるが、大企業ではむしろ1人あたりのPR数は減少する傾向
- AIを効果的に活用するための「技術的な土台」や「開発文化」がなければ、どれだけ投資しても無駄になる
- 個人の活用は多いが、組織の活用に繋げる必要がある
- 利用最適化に関心が移っていっている
- 採用動向
  - メガベンチャー：優秀なエンジニア
  - スタートアップ：シニア人材
  - 大企業（内製ベース）：従来ベンチャーが採用していた層を積極採用
  - 大企業（外注ベース）：Sierやコンサル出身者の歓迎度が高い
  - 受託/SIer：企画・要件定義のできる人材需要が高い
- 開発と経営が明らかに近くなっている
- AI普及の結果、むしろエンジニアに「技術力」を求めるという企業の声は強まっている
## Q&A
- ジュニアでも興味があれば、伸びる
- 以前よりも対面の面接の重要度が上昇している
- 若手～ミドル層では、自身の足りないスキルを補うために戦略的に受託企業へのキャリアチェンジをするケースも
- あきらかに募集が減った業種
  - スタートアップのフロントエンド
- 増えているのは
  - プロダクトマネージャ・プロダクトエンジニア
  - FDE
  - フルスタックエンジニア
