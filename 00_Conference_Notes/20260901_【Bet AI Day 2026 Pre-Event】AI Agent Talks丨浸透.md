# 便利なツールを作るだけでは終わらせない、組織実装と浸透 of 工夫
- バクラク事業部
  - 今日は、開発者
  - コーポレート部門の開発者
- シュパード
  - 開発を簡単にするツール
  - 手元でAIと繋げるツール
    - 公式MCPも無い頃
    - 第3者作成は、セキュリティが怖いなが開発きっかけ
- 2025年6月に作成
  - 最初の実装は、ask　ヒューマン
    - AIが質問したい時に質問する場所を1箇所にした
    - それまでは、人がAIが質問で止まっていないかをターミナル複数を巡回していた
- 最初は、気軽にこんなの作っていると言うと、数人がダウンロードしてくれる
- 徐々にslackとかGoogleとか連携されていって、ビジネス側にも広がっていた
  - 先進的なビジネス側に取り入れられていった
  - 最初は、開発者向けだったので、Googleとかの連携を自分でクライアントとかやる設定だった
    - ビジネス側の設定が難しいという声や何からすれば良いか分からないという声で認識して改善するようになった
- ビジネス側から、○○だったら○○したいという要望が増えた
  - LLMの自然言語で書いた内容をプロンプトとして用意しとく
    - 定期実行
  - 「MCP使えるよ」では、分からないが、AIが定期実行を変わってくれるが理解しやすい
- 日報文化がある
  - それの自動化ができるのが、ビジネス側に好評
- slackのセットアップとこのシステムの自動アップロードが普及に大きかった
  - 2026年1月に入社したら、geminiのAPIキー発行が矢鱈来るのは、なんだろうなーと考えて、シェパードを触ってみようとなった
    - 鍵発行するだけの人になる前に、解決しようと考えた
  - 2026年2月にやった事ないけれど、サーバー立てて、エレクトロンを作った
    - 色々、ワンパスワードとかも考えたけれど
  - 自動アップデートは、お願いされて、検討しだした
    - グーグル認証とかも取っていたので、ストレージでバケットに権限付けといて
- どんなものを繋げているか
  - 文脈で使われるNMMとか
  - 画像生成とか
  - zen　デスクの読み書き
  - スノーフレイクが使われているから、それ
- メインは、開発者向けで坂さんがどんどんアップデートしていく
  - サービスコンソール
- 開発者の事例
  - どのサービスがどの状態かPRやデプロイ確認ができる
    - 自分のがいつデプロイされているかが分かる
    - 人がやると、あちこち見に行く必要がある
- 1時間くらいのハンズオンを何度も繰り返した
  - 自主的に参加した人は、アーリーアダプター
    - 参加者が、次に行ってみれば良いよ。便利だと口コミ
  - 1時間は、事例や簡単な使い方
  - 頻度：当時は、3週間1回で、全部で5回
    - 毎回、録画
      - 来れなかった人は、見れる状態
    - 最初は、まず使用できる状態か確認して、セットアップから
      - 最初は、開発者向けのままだったので
    - 後半の回では、最初から事例だけできるようになった
      - また、使用しているビジネス側がさらに事例共有
    - 野良の別のハンズオン・事例共有会も現れる
- 名前がユニークだから、エゴサーチしやすかった
  - 使えないと呟いている方に、直接質問しに行っていた
  - 30分に1回検索していて、それでも新しい投稿が必ずある状態
- 全社の当たり前になったのは、なぜ？
  - 構築したライトLLMがあって、各個人の利用状況が可視化されていなかった
    - これを素で使用すると、セットアップが難しい
    - これのようなセットアップ基盤が必要となった
      - セットアップもシェパード上で、ボタンポチで出来るようにした
- 次の段階
  - キーの管理
    - 短命にしたい
  - 個人の利用率と状況の可視化
    - それが、アウトカムに繋がっているか
- 最初は、ライトLLMは、CLIで考えていたが、ビジネス側に馴染みがない
  - そのタイミングで、あちらこちらから、シェパードが浸透していると言われて。。。
    - シェパードと連携してやることに
      - ユーザーが意識する事なく、安全にキーをローテーションする
- Windowsユーザーにも対応できる
- lightLLM予算上限申請
  - 自動で申請して、管理職が許可
    - 許可後に則反映
    - しかも、予算上限と自分がいくら使用しているかも見れるようになっているから、予算感覚が個人で身につく
    - 上限来ると、自動で申請ボタンが出て来る
      - Slack通知も来る
    - コスト管理は、したいがAI利用を止めたくないの両立
      - ビジネス側もセッション続けるとコスト高いとかが身に付いた
